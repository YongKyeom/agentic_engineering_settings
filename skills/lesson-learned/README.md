# Lesson Learned

Use this skill to reflect on an actual implementation, debugging event, or recurring mistake. It connects evidence to a practical takeaway and explains when the lesson applies again. Supplied notes or diffs are enough; Git history is one possible source.

Example requests:

- “What did this debugging session teach us?”
- “Extract a lesson from this commit and its test result.”
- “이 실수가 반복된 이유와 다음에 확인할 기준을 정리해줘.”

The [skill instructions](SKILL.md) define the workflow and scope. The [principle catalog](references/se-principles.md) and [anti-pattern guide](references/anti-patterns.md) are optional references, not required reading for every reflection. The default output is conversational; saving files, changing instructions, or updating persistent memory requires the corresponding user request.
