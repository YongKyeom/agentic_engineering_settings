# Humanizer

Edit existing text to remove formulaic AI-style phrasing and translationese while retaining facts, conditions, uncertainty, and the author's voice. Use it for “AI 말투를 줄여 줘” or “뜻은 그대로 두고 자연스럽게 고쳐 줘.” It does not determine who or what wrote the text.

> 이 설정은 알림을 끄는 역할을 수행합니다.
>
> → 이 설정은 알림을 끕니다.

The skill keeps necessary qualifications and intentional personality. It does not add opinions, personal experiences, citations, or concrete product features to make prose seem more human.

[SKILL.md](SKILL.md) contains the editing contract. [Pattern decisions](references/pattern-decisions.md) supplies optional examples for longer drafts. General drafting and document organization belong to `writing-clearly-and-concisely`; using both is optional.
