# Writing Clearly and Concisely

Draft and edit prose so readers can follow the point, conditions, and evidence without unnecessary wording. The skill preserves meaning, uncertainty, and the author's register, including Korean 높임말 and sentence endings.

Use it for requests such as “문서 흐름을 정리해 줘,” “의미는 유지하고 더 간결하게,” or “다음 오류 메시지를 이해하기 쉽게 고쳐 줘.” A short edit can return just the revised sentence:

> 이 기능의 사용을 위해서는 먼저 로그인을 진행해 주셔야 합니다.
>
> → 이 기능을 사용하려면 먼저 로그인하셔야 합니다.

[SKILL.md](SKILL.md) contains the workflow and optional reference links. The `elements-of-style/` files preserve historical English guidance; they are not current rules for every language or publication. The archived [Wikipedia field guide](signs-of-ai-writing.md) is relevant to requests about AI-writing indicators, not a required reading list for editing.

For a focused request to remove formulaic AI-style phrasing, `humanizer` has that narrower role. The skills can be combined when useful; neither requires the other.
